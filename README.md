# Sejuta Jiwa — GitHub Pages

Versi static dari website Sejuta Jiwa yang siap dipublikasikan menggunakan GitHub Pages.

## Halaman
- `index.html`
- `menu.html`
- `about.html`
- `contact.html`
- `blog.html`
- `keranjang.html`
- `pembayaran.html`
- `pesanan-berhasil.html`

## Catatan
Website tidak membutuhkan PHP atau MySQL untuk versi ini. Keranjang dan data pembayaran demo menggunakan `localStorage` pada browser.

## Publish
Upload seluruh isi folder ini ke repository GitHub, lalu aktifkan **Settings → Pages → Deploy from a branch → main → / (root)**.

Video `assets/video/sejuta-jiwa.mp4` berukuran sekitar 80 MB. Jika upload lewat terminal/GitHub Desktop, file ini masih berada di bawah batas 100 MB per file GitHub. Upload melalui tombol web GitHub memiliki batas file yang lebih kecil, jadi gunakan GitHub Desktop atau Git untuk repository ini.
